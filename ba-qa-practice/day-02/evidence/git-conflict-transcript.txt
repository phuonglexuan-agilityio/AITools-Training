Git block (Day 02): pull --rebase, reading git log / git diff, resolving merge conflict #1
Where: a throwaway local repo (Alice = me, Bob = partner) created by Claude in a sandbox.
Not the AITools-Training repo. File used: ticket.md with a made-up skip-month ticket.
