# Q3: Drafting task

## Prompt (version 1, basic)

```
Write an email to a client asking about the skip month feature.
```

## Prompt (version 2, improved)

```
Draft a short, polite email to a client asking them to clarify the deadline and who can use a
"skip a month" button. Keep it under 120 words.
```

## Answer used (from version 2)

**Subject:** Quick questions on the "Skip a month" button

Hi [Client name],

Thank you for the request. Before we plan the work, could you help with two points?

1. **Deadline:** is there a hard date (for example the holiday sale), or is it a target?
2. **Who can use it:** all subscribers, or only some plans? Should gift subscriptions be
   included?

A short reply is enough. Once we have this, we will send you a one-page summary to confirm.

Best regards,
[Your name]
